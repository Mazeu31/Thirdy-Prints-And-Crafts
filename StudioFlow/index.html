1. Firebase configuration

Firebase Console → Project settings → Your apps → Web app → SDK setup and configuration.

NOT SAVED

The Firebase web config identifies your Firebase project; security is enforced by Authentication and Firestore Rules, not by hiding this config.

2. Sign in

Enable the Google provider under Firebase Authentication. Each Google account gets its own private task collection.

3. Sync mode

Auto Sync saves every change to Firebase. Manual Sync keeps edits local until you press Sync now.

● UNSYNCED CHANGES

Recommended: Auto Sync for normal daily use. Switch to Manual before bulk imports or major cleanup if you want to review changes before sending them to Firebase.
